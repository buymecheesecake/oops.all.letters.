# ⋆˚✿˖° oops.all.letters.  
oops.all.letter. welcomes you to a typographic accident of epic proportions.  

## 🤷 What Does It Do?  

oops.all.letter. replaces every visible character on your browser with mutated, misbehaved, or aesthetically chaotic glyphs. It’s like your font went on a hallucinogenic trip and took the alphabet with it.

## ✨ Features

- Replaces all letters with random (but weirdly beautiful) alternatives
- Keeps punctuation, numbers, and structure—barely
- Guaranteed to confuse your enemies and delight your inner chaos goblin
- Absolutely no productivity benefits

## 🔧 How to Use

1. Download the `.zip` of this extension
2. Go to `chrome://extensions/`
3. Enable Developer Mode
4. Click Load unpacked
5. Select the folder
6. Witness alphabetical anarchy

Because sometimes you don’t want to read the news, you want to feel it.
